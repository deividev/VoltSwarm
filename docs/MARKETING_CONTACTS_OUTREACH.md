# Voltswarm — lista de contactos para promoción orgánica

> **Estado:** lista inicial de investigación, 30-07-2026. No implica contacto, publicación, pago ni compromiso de cobertura. Antes de cada envío hay que verificar la política vigente del canal, sus datos de contacto y el ángulo editorial.

## Reglas de contacto

- Contacto profesional por correo, formulario o convocatoria pública; no replies promocionales ni DMs genéricos.
- Sin servicios de pago, bots, engagement pods ni promoción no declarada.
- No comunicar una fecha de lanzamiento hasta que esté públicamente confirmada.
- La página de Steam no es por sí sola una noticia: el pitch necesita un tráiler, hito jugable, demo/build o noticia concreta.
- Cada contacto recibirá una UTM propia para medir visitas y wishlists atribuibles.

## Material base que debemos preparar

| Material | Uso |
| --- | --- |
| Press kit en inglés de una página | Explicar el juego, equipo, género, Steam URL y puntos verificables. |
| Steam URL con UTM por contacto | Medición individual; nunca reutilizar la misma UTM entre canales. |
| 3 capturas PNG 1920×1080 | Prensa, correos y fichas. |
| MP4 de gameplay 10–15 s, 1080p | Primer contacto y redes; no GIF. |
| Tráiler nuevo 6–15 s | Prioridad septiembre, especialmente Japón. |
| Build privada estable y claves | Solo para creadores seleccionados cuando represente bien el juego. |
